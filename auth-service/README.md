# Auth Service

Сервис аутентификации и авторизации для VPN системы.

## Функциональность

- Регистрация пользователей
- Авторизация пользователей
- JWT токен аутентификация
- Управление профилем пользователя

## API Endpoints

### Публичные эндпоинты
- `POST /api/auth/register` - Регистрация нового пользователя
- `POST /api/auth/login` - Авторизация пользователя

### Защищенные эндпоинты (требуют JWT токен)
- `GET /api/auth/me` - Получение информации о текущем пользователе

## Структура запросов

### Регистрация
```json
{
  "email": "user@example.com",
  "password": "password123"
}
```

### Авторизация
```json
{
  "email": "user@example.com", 
  "password": "password123"
}
```

### Ответ с токеном
```json
{
  "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "tokenType": "Bearer"
}
```

### Информация о пользователе
```json
{
  "email": "user@example.com",
  "username": null
}
```

## Настройка

### Переменные окружения
- `POSTGRES_USERNAME` - имя пользователя БД (по умолчанию: root)
- `POSTGRES_PASSWORD` - пароль БД (по умолчанию: 9qwe1ox)
- `POSTGRES_AUTH_URL` - URL БД (по умолчанию: jdbc:postgresql://localhost:5433/auth-service)
- `JWT_SECRET` - секретный ключ для подписи JWT токенов
- `JWT_EXPIRATION` - срок действия токена в миллисекундах (по умолчанию: 7 дней)

### База данных
Сервис использует PostgreSQL с Liquibase для миграций. Таблица `users` создается автоматически при запуске.

### Безопасность
- Пароли хешируются с помощью BCrypt
- JWT токены подписываются секретным ключом
- Срок действия токена по умолчанию: 7 дней

## Запуск

```bash
./mvnw spring-boot:run
```

Сервис запустится на порту 8081.
